# V1.4 installed-iPhone acceptance

Do not merge until a human accepts this release on an actual iPhone. Automated coverage uses desktop Edge mobile emulation only. Use an HTTPS build of feature/v1.4-ios-experience installed to Home Screen; the production GitHub Pages URL remains on main until merge. Use a test round without clearing valuable real rounds. Install the ChatGPT app for its handoff test.

1. Fully close and launch Caddie. Home must appear first, including when a round exists. Confirm Home/Play/Rounds fit above the home indicator and below the notch in portrait and landscape.
2. With no active test round, tap Play. It should offer Start Round. Return Home, select Nevel Meade, then Blue, then Start Round. Existing active rounds must require deliberate replacement confirmation; cancel if testing with a real round.
3. Verify Overview course facts, Blue yardage/rating/slope, then Game Plan and Hole 1. All supporting information must remain available.
4. On Hole 1, immediately locate club, target, yardage, par, handicap, Ask Caddie and Record Score. Neither action should require scrolling through the advice on a normal portrait viewport. Open Full hole plan to inspect the original strategy.
5. Open Record Score. Verify a sheet over the hole, only one set of fields, touch-friendly choices, scroll containment and a visible Done action. There must be no scrolling of the underlying hole while the sheet is open.
6. Record Hole 1 score 5, Fairway, GIR No, 2 putts and 0 penalties. Valid taps save immediately, as labeled. Tap Done; verify the main score action shows 5. Reopen and check all entries.
7. Choose 7+, enter 12, then test a lower exact score of 1. Test 0, a negative number and a decimal: invalid values must not overwrite the last saved score and Done must reject them. Restore 5. Close the sheet and reopen; valid results remain.
8. Add note "iPhone H1 test". With the keyboard visible, scroll and reach Done without losing the note. Try larger system text, landscape, and a smaller viewport if available. Dismissing via the close control must preserve entered valid fields.
9. Advance to Hole 2 with Next, record score 5 and a note, then advance to Hole 3 and record score 5. Verify Summary shows 15 strokes and +2 through the three completed holes. Return to Hole 3.
10. Switch Home, Rounds and Play. Play must return to active Hole 3 with every score/note intact. Home Resume must identify Nevel Meade, Blue, Hole 3 and +2.
11. Use the hole selector to browse Hole 14 without entering results. Only the 18 holes belong in this selector. Switch tabs and return Play: the saved active hole remains Hole 3. Previous at Hole 1 and Next at Hole 18 are disabled; no presentation counters remain.
12. Open the round menu, reference Course Overview and Game Plan, and return to Current Hole 3. Open Summary directly. These actions must not restart the round or change results.
13. On a par 3, open scoring and verify Tee N/A with no fairway choice. Verify putts 3+, penalties 2+, exact values, toggle clearing and optional blank fields.
14. Return Hole 3. Use Ask Caddie / JUST COPY, paste elsewhere, and verify current hole, recent holes, scores, notes and bag distances. Confirm exactly one Ask event in the full Golf Coach export.
15. Use COPY CONTEXT & OPEN CHATGPT. Confirm copy precedes launch. Paste manually in Golf Coach; note whether iOS opens native ChatGPT or web. Return to Caddie: the same view remains if not reloaded; after an iOS reload, Home must offer Resume to Hole 3. Verify all data/events.
16. Use Exit to Home in Summary or the round menu. The round must remain active. Fully close/relaunch: Home first, then Resume directly to Hole 3. Browse course/tee setup and cancel replacement; the active round must survive.
17. After an online load, enable airplane mode. Relaunch, Resume, switch tabs, reference Overview/Game Plan, score and edit notes. Core actions must work; the external ChatGPT conversation itself needs connectivity.
18. Enter scores for every remaining hole. Open Summary from Hole 18. Review totals, front/back, FIR/GIR/putts/penalties and the complete scorecard. Scroll horizontally for notes if needed; text must remain readable. Copy for Golf Coach must include all results/notes/events.
19. Cancel Finish once and verify the round stays editable. Finish and confirm: Home appears only after successful save; active Resume disappears. Missing scores must prevent finalization.
20. Open Rounds, reopen the completed scorecard and export it. Reload offline; history must persist. Start another test round without altering the archived one.

Also test clipboard denial/manual fallback, reduced motion, sunlight legibility, VoiceOver labels/focus, and accidental horizontal gestures: gestures must not change holes or scores. Record device/iOS version, viewport/orientation and any blocked controls. Never report actual-device acceptance from emulation alone.

Behavior choices for review: valid scoring fields save immediately rather than buffering until Done; blank optional fields remain blank. Play opens the active hole rather than the last browsed reference. Hole-only navigation stops at 18; Summary is separate. These choices preserve the current scoring model while separating application and round navigation.
